# Asset generator

This Python script will create a small set of PNG sprites and WAV audio files into assets/output_images/ and assets/output_audio/.

Requirements
- Python 3.8+
- Pillow: pip install pillow

Run
python assets/scripts/generate_assets.py

Files produced (examples)
- assets/output_images/sprites/lidia_walk_0.png, ... _1.png, _2.png
- assets/output_images/sprites/shura_walk_0.png, ...
- assets/output_images/tiles/dungeon_floor.png
- assets/output_images/tiles/dungeon_wall.png
- assets/output_images/tiles/lava.png
- assets/output_images/ui/game_logo.png
- assets/output_audio/title_loop.wav
- assets/output_audio/dungeon_loop.wav
- assets/output_audio/sfx_hookshot.wav
